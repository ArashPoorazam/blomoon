# Processes

One job: document real movements through the implemented app. These are not plans.

## Inputs

- Reference: `../CONTEXT.md`
- Reference: `../_meta/schema.md`
- Objects: linked cards in each process frontmatter
- Source: cited repository files in each process

Do not add a process card for an aspirational workflow. Mark future behavior in an object card as `ghost` or leave it out.

## Output

Process cards that identify input, movement, output, first-order impact, and source citations.

## Human Check

Before using a process to drive changes, follow at least one cited step into source and confirm the flow still exists.
