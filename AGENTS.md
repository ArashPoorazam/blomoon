# Agent guidance

For podcast, live TV, or media-platform scaling work:

- Read `docs/media-expansion-plan.md` and `docs/media-expansion-progress.md` before implementation.
- Treat the progress file as the authoritative record of step status, current work, decisions, verification evidence, and handoff notes. Reconcile it with the current code before continuing.
- Implement the requested step and its necessary dependencies. Update the tracker when starting, completing, or handing off work. Never mark a step complete without its acceptance evidence.
- Preserve existing radio behavior and saved user data. Follow the verification and migration requirements in the plan and README.
- Planning documents do not themselves authorize paid provisioning, production changes, publication, or optional scope. Follow the user's current authorization.

For unrelated work, these documents are context only; do not expand the task into this roadmap.
